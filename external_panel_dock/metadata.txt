description=Organize QGIS panels, dockable attribute tables and feature forms in an independent, resizable window for multi-monitor workflows.
about=External Panel Dock creates a separate window that groups QGIS dock panels, plugin panels, dockable attribute tables and supported dock panels. Automatically collect newly opened native attribute-table docks, or arrange existing panels as tabs, side by side or vertically, change their order and move the entire workspace to another monitor. The window provides standard minimize/maximize controls and a Return all command to restore the original windows. Open or floating panels are collected using a selection dialog with separate categories and Select all / Deselect all actions. Standalone QGIS attribute dialogs are excluded for stability; dock them using the QGIS dock control first.
